## Get started developing

#### Set up the project

**1. Getting the source code**
  1. **!IMPORTANT** Install Git Large File Storage extension from **https://git-lfs.github.com/**
  2. Clone the repository
  3. Checkout the latest release branch from origin
    1. In **Source Tree** you would do this by expanding the *Remotes* folder on the left, then going into *origin*, and double clicking the latest *release* branch
    2.**Manually** through the git command line: **git checkout -b release/8 --track origin/release/8** just replace the version with the current latest
  4. Make sure you're on that branch

**2. Set up Android Studio**
  1. Open the **Autoskola/Android/** folder in Android Studio
  2. Android Studio should automatically start downloading the project dependencies and building them
  3. Once that is done, you can try running the project on your physical or virtual device
  4. Install the **Fabric** plugin for Android Studio
